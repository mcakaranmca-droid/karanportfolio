# Public Assets Directory

This directory contains static assets for your portfolio website:

- `/images/`: Place your personal headshot, custom project mockups, or case study screenshots here.
- `/videos/`: Place your showreel MP4 video files or short-form video snippets here.
- `/icons/`: Custom vector SVGs or favicon badges.
- `resume.pdf`: Drop your official resume PDF here to link it directly from the hero or about sections.
